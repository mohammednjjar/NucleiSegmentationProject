Custom Nuclei-Specific Binning for High-Resolution Gene Expression Mapping
This project explores an innovative approach to gene expression mapping by using nuclei-specific binning rather than traditional grid-based binning.
By leveraging 10x Genomics Visium HD Gene Expression Data and StarDist for nuclei segmentation, the goal is to achieve a more precise representation of spatial gene expression at the cellular level.

Project Objectives

Segment cell nuclei in high-resolution images with StarDist.
Use custom binning to group gene expression data by individual nuclei.
Analyze and visualize gene expression patterns at a detailed, cellular scale.

Tools and Libraries

StarDist for segmentation of cell nuclei.
AnnData and Scanpy are used to manage and analyze spatial transcriptomics data.
GeoPandas and Shapely for geospatial processing.
Matplotlib for visualizing results.
